Engramma 0.6.17-beta.1 — the capture behind the Engramma docs
=================================================================

Every command and output quoted by the pages under /docs/engramma/ comes from
this session: the released binary (commit 1bfc611), installed by the release
installer into a temporary folder, on a fresh data root (ENGRAMMA_ROOT and
ENGRAMMA_MODEL_DIR inside <tmp>), with the synthetic notes of the site (Gaia,
Milano, Torino, Acme). Output is verbatim, in Italian, as the CLI prints it;
what was changed: paths are shortened (<tmp> is the temporary folder of the
session) and the capture script's own bookkeeping lines are left out.

The proposing client of S5 and S12 is a stdio MCP driver carrying the
configuration Claude Code would carry (`--actor claude-code`, so the engine
signs `mcp:claude-code`): the engine side is real, the client side is the
driver (`client dichiarato: site-capture-driver 0`). The model was pulled once,
before S3, from its pinned revision.

One engine defect found while capturing, to declare to Engramma: with a single
decision id, `engramma revert <id> --dry-run` REVERTS for real (the dry-run
check sits after the call in run_revert); --dry-run is honored on the bulk path
only (S12). The docs say what the binary does.
