---
title: Skill
description: Ricette che insegnano a un bot come fare un lavoro nel modo che piace a te.
---

Una **skill** è una ricetta: i passi, il formato e i dettagli di un lavoro, fatto nel modo
che piace a te. Un bot che ha una skill la segue ogni volta.

## Da dove arrivano le skill

- **Le scrivi tu**: apri la pagina **Plugin**, premi **Aggiungi** e scegli **Crea una
  skill** — oppure **Crea con un bot**, che apre la chat con la richiesta pronta.
- **Le salva un bot**: dopo un lavoro riuscito, chiedi al bot di salvarlo come skill. Il
  bot propone la modifica con una card di approvazione — «{bot} vuole cambiare le skill»
  — e tu la consenti o la rifiuti.
- **Il catalogo**: la sezione **Sfoglia** offre un elenco curato di skill, scaricate da
  repository GitHub al commit esatto che il catalogo fissa.
- **Le tue altre app**: **Importa skill** porta dentro le skill già presenti sul tuo Mac
  da Cursor, Claude Code, Codex o ZCode.
- **Plugin**: un plugin in formato Claude Code può portare skill e server MCP. Homun non
  esegue mai hook o comandi di un plugin; quando un bot vuole installarne uno, arriva una
  card e decidi tu.

## Trovare e usare le skill

La pagina **Plugin** elenca tutte le skill, con la ricerca per nome; ogni skill dice da
dove arriva, e quelle con un'origine GitHub si possono aggiornare da lì.

I bot scelgono da soli la skill giusta quando una richiesta le corrisponde. Alcune skill
partono solo quando le chiami con **/** nella chat.
